# Batch 09 source attribution

Documentation snapshot for preparation and integration review, 13 September 2026. This is not a delivery or verification certificate. The per-building ledgers retain individual rights statements, capture dates, image hashes and inspected/rejected status. No reference-photo pixels are exported as textures. Geometry interpretation and estimated dimensions are adaptations; the photographs are not metric surveys. Do not collapse the following different source licences into a blanket licence.
